# 关联图像笔记 —— 「说/听到什么话 → 什么表情」

> 本文件是《魔法使之夜》人格蒸馏任务的产出物之二。
> **规则不是发明的，是从原文叙述行提取的**：本作叙述承担了「演出指示」职能，
> 17,050 行叙述中有 2,000+ 处表情/情绪标注，这些标注就是原作写好的差分切换指令。

## 数据来源与方法

| 项 | 值 |
|---|---|
| 语料 | `game_scripts/ctd/data00200.hfa/script_text_ja.ctd`（24,134 行，全文） |
| 读取方式 | 32 片重叠分片，每片一个子 agent 通读，无采样无跳读 |
| 提取出的表情/演出指示 | **%d 条**（去重后） |
| 提取出的心理描写 | 949 条 |
| 提取出的说话人归属 | 2223 条 |
| 素材来源 | `hfa_png/out/` 下 23,747 张已解出的 PNG |
| 素材编目 | 逐格视觉判定 1094 格（人眼/视觉模型），**未使用任何推测的编号表** |

⚠️ **重要发现**：立绘文件名的 `i4` 字段**不是全局表情编号**。
同一 `i4` 在不同 `i3`（姿势家族）行、不同服装下含义不同；
**同一 `i3` 行内的不同 `i4` 才是「同一张脸的多个表情」**。
因此表 3 是按**逐格视觉判定**得到的，不存在可复用的 `i4 → 槽位` 查表。

> 有珠全篇 `neutral` 79 次对 `smile` 7 次、`laugh` 1 次，原作根本没给她配大笑或大怒的差分；
> 金鹿更极端——**全库只有 2 种表情**（`i4=01` 睁眼平静 / `i4=07` 闭眼微笑），
> 5 套服装一致，所以除 `neutral`/`smile` 外 10 个槽位全部走回退。
