# 怎么打开 Console 并把诊断结果发出来

> 目的：确认「皮肤的浏览器半边到底有没有跑起来」。
> 只有重启 DSH 之后 `health` 路由才存在，所以**先重启，再照下面做**。

---

## 第一步：打开控制台

在**显示 DSH 界面的那个浏览器窗口**里，任选一种：

| 方式 | 操作 |
|---|---|
| **最快** | 按 `F12` |
| 键盘 | 按 `Ctrl` + `Shift` + `J`（直接跳到 Console） |
| 鼠标 | 页面**空白处**右键 → **检查 / Inspect** → 顶部找 **Console** 标签 |
| 地址栏 | 输入 `edge://devtools/` 或 `chrome://devtools/` 回车 |

> Edge 和 Chrome 都一样。面板通常在右边或下边弹出来。

---

## 第二步：切到 Console 标签

面板顶部有一排标签：`Elements` / `Console` / `Sources` / `Network` / …

**点 `Console`**（中文版叫「控制台」）。

看到最下面有一行以 `>` 开头的输入框，就是它。

---

## 第三步：粘贴这一行，按回车

```js
fetch("/moye-skin/health").then(r=>r.json()).then(j=>console.log("=== diag ===",JSON.stringify(j.diag,null,1),"=== loader ===",JSON.stringify(j.loader,null,1))).catch(e=>console.log("FETCH FAILED",e))
```

**如果控制台不让你粘贴**（Chromium 系第一次会拦，并提示 "Warning: Don't paste code..."）：

1. 在输入框里手动输入 `allow pasting`（就这两个单词）
2. 按回车
3. 再粘一次那一行

---

## 第四步：把结果发我

按回车后会打印两段 JSON，大概长这样：

```
=== diag === {
 "hostStartedAt": "...",
 "clientSeen": true,
 "clientFirstSeen": "...",
 "clientInfo": { "stage": "ready", ... },
 "clientErrors": []
}
=== loader === {
 "entries": 87,
 "candidates": [ { "package": "dsh-skin-mahoyo", "clientExists": true, ... } ],
 "missing": []
}
```

**把这两段一起复制发我。**

---

## 结果怎么读（你也可以自己先看一眼）

只看 `diag.clientSeen` 这一个字段就够定性了：

| 看到什么 | 含义 | 接下来 |
|---|---|---|
| `"clientSeen": false` | 客户端 bundle **根本没到浏览器** | 看 `loader` 段：`candidates` 里有没有 `dsh-skin-mahoyo`、`clientExists` 是不是 `true`、`missing` 里有没有东西 |
| `"clientSeen": true`，`clientErrors` 是空的 | 客户端跑起来了，注册也成功了 | 问题在"渲染出来但看不见"——我看 `clientInfo.stage` 是哪一步 |
| `clientErrors` 里有 `"apply-failed"` | `apply()` 抛错，被我的兜底接住了 | 错误栈就在那一段里，直接能定位 |
| `clientErrors` 里有 `"render-failed"` | 渲染抛错 | 同上 |

---

## 如果连 `FETCH FAILED` 都没打印出来

说明粘贴的那行本身没跑（比如被控制台拦住）。换个更短的试：

```js
fetch("/moye-skin/health").then(r=>r.text()).then(t=>console.log(t))
```

还不行就说明**连宿主路由都没了起来**（那宿主半边也没加载），直接在终端里验证：

```powershell
curl.exe -s http://127.0.0.1:3080/moye-skin/health
```

有输出 → 路由活着（问题纯在浏览器侧）；
报错/404 → 插件整个没加载，跑 `pwsh -File "D:\QuickLook插件包\moye\skin\tools\guard.ps1"` 看预检。
