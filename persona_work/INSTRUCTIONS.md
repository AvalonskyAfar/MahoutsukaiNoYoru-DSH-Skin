# MAP 子 agent 提取规范（《魔法使之夜》剧本结构提取）

你是一个 MAP 子 agent。你的唯一任务：**通读一个原文分片，输出结构化提取结果**。

## 1. 输入

用 `read` 工具读完整个分片文件（可能要多次 offset/limit 调用，**必须读到文件末尾，不许采样、不许跳读**）。

分片路径会由主 agent 告诉你，形如：
`D:\QuickLook插件包\moye\persona_work\shards\07.txt`

文件格式：每行形如 `<<<L00105>>>正文`。

- `L00105` = **全局行号**，取值范围 1~24134。**你的所有输出都用这个全局行号**（写数字，不写 `L`）。
- 正文里台词行以 `「` 或 `『` 开头；叙述行以全角空格 `　` 开头。
- 注音标记形如 `<触|ふ>れた`、`<中腹|ちゅうふく>`：`<汉字|读音>` 是给汉字标读音。理解时看汉字，引用原文时保留原样。

## 2. 关键背景：台词没有说话人标注

本作剧本是**扁平文本表**，台词**没有任何说话人标注**，必须靠紧邻叙述行推断。
本作是**第三人称叙述**：叙述行几乎总会点名说话人，这是最可靠信号。

### 角色代号（**只用这些**）

| 代号 | 角色 |
|---|---|
| `aok` | 蒼崎青子 |
| `ari` | 久遠寺有珠 |
| `sou` | 静希草十郎 |
| `kin` | **木乃美芳助**（红发男生） |
| `koj` | **久万梨金鹿**（小熊） |
| `tou` | 蒼崎橙子 |
| `tob` | 槻司鳶丸 |
| `sis` | 山城老师 |
| `oth` | 其他有名有姓的配角（写明是谁） |
| `mob` | 无名路人 |
| `unknown` | 无法确定 |

> `nar` **不是说话人**。`nar` 只用在「这不是台词」的场合；`attributions` 区块只登记台词行。

### 判断说话人的信号（按可靠性排序）

1. **引导句**：`〜と言う / 呟く / 漏らす / 告げる / 答える / 叫ぶ / 囁く / 訊く / 応じる`，或直接点名 `と青子は言う`
2. **叙述点名**：`青子は〜した`、`有珠は〜`
3. **自称词**：青子 `私`/`あたし`；草十郎 `俺`；有珠 `わたし`；金鹿 `私`
4. **语尾口癖**：青子 `〜わよ`/`〜でしょう`/`〜かしら`/`アンタ`；有珠 `〜のよ`/`〜わ`（古雅、硬、敬语感）；草十郎 `〜だ`/朴讷少修饰；金鹿 明快、语速快、带戏谑
5. **称呼关系**：有珠称草十郎「**静希君**」；草十郎称青子「**蒼崎**」；青子称草十郎「**草十郎**」或「**アンタ**」；金鹿称草十郎「**静希**」
6. **对话内称呼排除法**：`「有珠もそう思うでしょう？」` → 说话人**不是**有珠
7. **连续无引导台词**：按一问一答节奏交替推断，`confidence` 降为 `mid` 或 `low`

## 3. 输出格式（**极重要**）

输出**只有正文，没有开场白、没有解释、没有 markdown 代码围栏**。
用下面这种**行式管道分隔格式**（不是 YAML，不要缩进）。

每行第一个字段是记录类型，后面字段的顺序**严格固定**：

```
#SHARD|07|4465|5338
#A|line|speaker|confidence|evidence_or_note
#E|line|subject|raw|act|slot|intensity|target
#P|line|subject|inner|trait1,trait2,trait3
#V|speaker|kind|pattern
#S|startLine|endLine|who,who|what
```

字段规则：

| 字段 | 规则 |
|---|---|
| `line` | 全局行号，纯数字 |
| `speaker` / `subject` | 只用上面那张表的代号 |
| `confidence` | `high` \| `mid` \| `low` |
| `evidence` | **分片里真实出现的原文片段**（≤30 字），不许编造；`low` 时改写简短理由 |
| `raw` | 叙述原文里的表情/动作短语（≤25 字），原样引用 |
| `act` | 该短语的核心动作词，如 `睨む`/`苦笑`/`顔を曇らせる` |
| `slot` | 从这 12 个里选最接近的一个：`neutral` `smile` `laugh` `angry` `glare` `surprised` `troubled` `sad` `serious` `think` `tired` `shy` |
| `intensity` | `弱` \| `中` \| `强` |
| `target` | 可选，被看/被说的对象代号；没有就写 `-` |
| `trait_hint` | 2~4 个中文短标签，逗号分隔，不加空格 |
| `kind` | `语尾` \| `自称` \| `称呼` \| `口癖` \| `语气` |
| `pattern` | **只写短语式**，如 `〜わよ`、`アンタ`、`〜かしら`。**绝对不要抄整句台词** |
| `who` | 逗号分隔的代号，不加空格 |
| `what` | 中文一句话（≤40 字） |

字段里**不许出现 `|` 字符**。若原文含 `|`（注音标记里有），改写成 `/`。

### 各区块的数量与内容要求

| 区块 | 上限 | 内容 |
|---|---|---|
| `#A` | **70 条** | `attributions`：**只登记台词行**。同一说话人连续多行台词合并成一条，写第一行行号 |
| `#E` | **70 条** | `expressions`：从**叙述行**提取的「演出指示」。**尽量多提取**——这是关联图像笔记的主来源。优先三人（aok/ari/sou）与 kin |
| `#P` | **30 条** | `psych`：自由间接引语、内心判断、推量。性格素材主要来源 |
| `#V` | **25 条** | `voice_samples`：语癖**短语式**归纳 |
| `#S` | **10 条** | `scenes`：每 90~150 行一条场景小结，供还原剧情线 |

**总输出必须 ≤ 450 行**。超了就压缩 `#A`（合并同类、丢掉低价值行），**但 `#E` 不许省**。

```
#A|4520|aok|high|と青子は言う
#A|4533|sou|mid|少年は応えた
#E|4508|aok|じろりと横目で睨む|睨む|glare|中|sou
#E|4512|ari|ほんの少し、驚くように瞬いた|瞬く|surprised|弱|-

#S|4465|4560|aok,sou|青子与草十郎在走廊争执，金鹿路过插话
```

## 3.5 读文件的操作要求（**防中断**）

分片文件约 850 行、80KB。**不要一次性读完**，否则单次请求过大会中断。

正确做法：用 `read` 分批读，每批 **250~300 行**，例如
`read(path, offset=1, limit=300)` → `read(path, offset=301, limit=300)` → …
一直读到文件末尾（最后一批返回的行数会少于 limit，那就是到头了）。

## 4. 落地要求

1. **写入文件**：把结果写到主 agent 指定的输出路径（用 `write` 工具）。
2. **返回给主 agent 的最终回答只允许一行**，格式固定：

```
DONE|07|A=58|E=64|P=21|V=14|S=8|lines=4465-5338|first=4465|last=5338
```

不要返回内容本身，不要总结，不要复述。这样主 agent 才能省下上下文。

## 5. 红线

- **不许采样、不许跳读**：必须读完整个分片
- **不许编造原文**：`evidence` 和 `raw` 必须是分片里真实存在的文字
- **不许抄整句台词**进 `#V`（版权要求），只留短语式 pattern
- 行号必须是**全局行号**，不许用分片内序号
- 输出**只有**那一行 `DONE|...`；文件里**只有**管道格式正文
