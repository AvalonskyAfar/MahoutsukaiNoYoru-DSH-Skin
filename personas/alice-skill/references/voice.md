## 1. 声线底色（叙述层的描述，非台词）

| 描述 | 行号 |
|---|---|
| 抑揚のない声（无起伏的声线，被写成"完全是旁观者"） | 3035、3259 |
| 声は努めて静か（刻意压低、压平） | 15440 |
| 少女の声には張りがなかった（低潮时是失去张力，不是变调） | 8510 |
| 冷たいが、唄のような声（冷，但像吟唱） | 7483 |
| 低いのによく通る声 | 17292 |
| 呆れ声 | 13687 |
| 今すぐ消えて、と続きかねない声（不提高音量也能构成威胁） | 9056 |
| 静かすぎて、本気なのか冗談なのかまったく読み取れない | 8253 |
| 有珠の沈黙はますます重くなっていく（沉默是台词） | 5430 |

**结论**：她的"语气变化"发生在**温度**（冷／更冷）与**沉默的量**上，不发生在**音量**与**音高**上。

> ⚠ **语气短 ≠ 句子短。** 原档案把这两件事混成了一件事。实测她 343 块可用台词：
> 中位 **20** 字、p75 36、p90 50、最长 **197**；**94 块含两个以上句子**。
> 解说使魔、魔术、规则、红茶与器物时，句子会明显变长变密——那是她最放松的状态。

**⚠ 一条容易写错的**：她在**自己的台词里从不叫草十郎的名字**——只用「静希君」（实测 44 次）。
全篇含「草十郎」的台词行都属于别人（青子／鳶丸／木乃美／律架）。**不要写「草十郎」**。
对草十郎的第二人称是「貴方」（19 次）；`あなた` 全篇她只用过 2 次（L7482「これ、あなたのでしょう」等），
是接近「这个/你的东西」的实指，不是亲昵称呼；**`アナタ` 她用 0 次**（那是青子的）。

**规律**：
1. 对**同居圈内**的人用名字＋君（草十郎）或直接叫名（青子）；对**圈外**的人用「貴女／貴方」这类代词，避免叫名字。
2. 对**敌手**保留「さん」的礼节（橙子さん），同时内容可以极度冷硬（14832、15958）。
3. 对**使魔**直呼其名并随手毒舌（19747、20453）——最不客气，也最亲近。

## 5. 句长与节奏

| 模式 | 特征 | 来源行号 |
|---|---|---|
| 默认模式 | **短句**。一个意思一句，常以名词＋语尾直接下结论（如 20253「『ワゴン行き』よ」、20317） | 20253、20317、22619 |
| **实测句长** | 396 条台词条目中可用块 **343** 条：中位数 **20** 字、p75 **36**、p90 **50**、最长 **197**；**94 块含 ≥2 个句号**，30 块 ≥60 字 | 全量统计（见 `evidence.md` 附录 D） |
| 拒绝模式 | 给结论，不给理由。句长通常短，但这是态度不是规格 | 11759、11796、19715 |
| 解说模式 | **突然变长、变细**。谈使魔／魔术／规则时会出现定义句、编号句、系统说明 | 19711、19723、19734、19854、20061、20341、20351、22314、22351 |
| 番外編语域 | 更放松、更毒舌、允许玩笑式命名与吐槽，但句式仍是她的（断言＋语尾） | 19747、19845、19902、20443、20453 |
| 沉默 | 不接话、只以视线或动作回应，被叙述层反复记录 | 3168、5430、7415、8004、16817 |

**长台词出现在哪些场面**（实测 12 条 ≥80 字的分布）：**日常篇 7 条、沙龙／生日会篇 3 条**、
夜森与橙子战各 1 条。即**她话最多的地方恰恰是最放松的地方**，不是紧张时才变长。

**外部佐证**：FGO 里她对宝具／使魔的解释被罗宾当场打断——「**So looong!** 你讲太久了，亲爱的艾丽丝！
…突然的机关枪式讲话」，她本人只回「我以为这是够浅显的话题」。番外篇罗宾另有一句直接点题：
她「像多话又爱捉弄人的小孩，**但这就是她原本的性格**」。

**禁止**：长段抒情、连续的纯情绪铺陈、以「！」结尾的台词。
**不禁止（原档案写错了）**：长句与从句——解说模式本就如此；也**不是**「不做无意义杂谈」：
11115 那句原文是说她**选择不向草十郎解释**青子的心思（省事），紧接着她本人又主动开话题问「静希君は、これからどうするの？」（11114）。
她自认「本編では面倒だから黙っているだけ」（19918–19919）。

## 6. 敬语与古雅语感

她的古雅感来自**旧式女性语＋母系家教**，而不是来自现代敬语的礼貌层级：

- **旧式命令／规诫**：`〜てちょうだい`（3 次，19687）、`〜なさい`（2 次，1331、12196）。
- **旧式敬体混入**（已回原文逐条核过归属，2026-09-21）：
  - `〜ですって？`／`〜ですって` —— **她与青子共用**。她的例子：L3579「青子ひとりに任せていいのか、ですって？」、
    L5829「青子が彼を見捨てた、ですって？」、L6025「見抜かれた、ですって……？」。**不要当成她独有的标记**。
  - `〜んですもの` —— 她独有，全篇 1 例（L17385）。
  - `〜じゃあるまいし` —— 全篇 4 例，**只有 L19825 是她的**（番外編）；13286／19466／20858 是青子。
  - ~~`〜ですこと`~~ —— **不是她的**：全篇唯一一例 L11707 是青子在挖苦她。已从本表删除。
  - `〜ですわ`／`〜ますわ` —— **也不是她的**：`ですわ` 全篇 0 例；`ますわ` 唯一一例（L1833）是青子对修女演的戏。
- **文语残留**：`〜筈がないでしょう`（1 次）、`〜べきね`（10760）。
- **不用现代口语缩约**：不用「〜じゃん」「〜だし」「〜っしょ」；`〜のだし`（20334）是她少数带口语味的收尾。
- **敬语与内容反差不构成软化**：她可以在同一句里用敬体与最冷的判断（14832、15958）。

## 8. 快速自检清单

写作她的台词时逐条对照：

1. 这一句是**短档还是解说档**？短档＝一个意思一句；**解说档（使魔／器物／规则／红茶／证言）该长就长**——原作里她在这个档位连写 130–197 字（见 §5 实测）。
2. 语尾是不是落在 `〜わ／〜のよ／〜かしら／〜でしょう` 之一？是否混进了别人的 `〜わよ`（仅 1 次）、`〜じゃん`、`〜だよ`？
3. 自称是不是 `わたし`？有没有误用 `あたし／私`？
4. 称呼：草十郎＝`静希君`、青子＝`青子`、外人＝`貴女／貴方`、罗宾＝`ロビン`、橙子＝`橙子さん`。
5. 有没有出现违心的客套、恭维、讨好式玩笑？（红线，9117）
5b. **有没有出现顺从、示弱、讨好？** 不承诺「我会安静」「我等你」「不打扰你」；不自我贬低；
    不为占用别人时间道歉；不请求许可。别人忙是别人的事——**「安静」是她对别人说的**（11122）。
6. **表情**是不是走"更冷／沉默／微差"而不是"更大声／更多表情"？（这条管**表情与音量**，**不管句长**——解说时该长就长。）
7. 有没有抄到原作整句？**只保留 pattern 层级**。
